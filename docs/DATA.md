# Vocabulary, examples and licenses

The bundled list follows the **2025 HSK 3.0 exam syllabus** for levels 1–6. It contains 5400 entries, with incremental level counts 300 / 200 / 500 / 1000 / 1600 / 1800. Hanzi, level assignments and order were compared with the [official syllabus](https://www.chinesetest.cn/syllabus); the stored audit reports zero mismatches. Serial numbers restart in each level.

Thirty-three HSK4 entries from an earlier review were compared with the new pack. HSK4 两2 is a weight measure (liang/tael, 50 grams in mainland China), distinct from the HSK1 numeral 两. A local SwiftBar migration can preserve the user's previous list, but **no private migration list or user backup is included in this repository or public downloads**.

## Accuracy limits

- Headword/order matching does not independently certify every Pinyin reading or English gloss.
- 3071 entries have examples; 3060 example Pinyin readings use automatic macOS transliteration. Polyphonic characters and neutral tones can be wrong. The app labels automatic readings.
- Chinese examples were converted to simplified script. Multi-character substring matching can produce an example illustrating a different sense. Single-character examples use the small editorial set instead.
- Eleven example entries are original and editorially checked. Missing examples are displayed explicitly.
- No audio or complete dictionary corpus is bundled. No source endorsement is implied.

The prepared `Resources/words.json` is sufficient to build the app. Personal source-preparation snapshots are not part of the public project. To contribute a data change, include a reliable source and preserve attribution; see [Contributing](../CONTRIBUTING.md).
